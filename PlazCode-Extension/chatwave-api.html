ChatWave API · PlazCode

Natywne narzędzia do pracy ze Studio

Połącz swoje konto ChatWave

Użyj klucza z ChatWave → Settings → API keys. Dostępność narzędzi zależy od API i wybranego modelu.

Wiadomości, referencje i wyniki narzędzi będą wysyłane do ChatWave. Obowiązują limity i zasady Twojego konta API.

Klucz pozostaje w pamięci tej karty. Zamknięcie lub odświeżenie karty usuwa go. Nie wpisuj klucza w rozmowie z modelem.

Wpisz klucz lokalnie, aby sprawdzić dostęp do API.

Start Agent sprawdza rzeczywisty odczyt listy narzędzi. Zatrzymaj zadanie paskiem PlazCode lub przyciskiem Stop.
